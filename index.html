La onda cuadrada de entrada es integrada por el circuito RC con retroalimentación negativa, produciendo una onda triangular cuya pendiente es proporcional a la amplitud de entrada dividida por τ = RC. A mayor τ, menor la amplitud de salida.

📋 Observación

El diferenciador amplifica las altas frecuencias (H ∝ ω), por lo que el ruido de alta frecuencia es fuertemente amplificado en la salida. Sube el deslizador de ruido para ver cómo distorsiona la señal cuadrada ideal. En práctica se agrega una resistencia en serie con C para limitar esta ganancia.

📋 Observación

Ambos filtros comparten la misma fc = 1/(2πRC) y la misma pendiente −20 dB/dec. La diferencia clave: el filtro activo amplifica en la banda de paso (ganancia DC = K) y tiene baja impedancia de salida. El pasivo tiene ganancia máxima de 0 dB.

📋 Observación

El filtro Sallen-Key de 2.° orden presenta una pendiente de −40 dB/década, el doble que 1° orden. Para Q = 0.707 (Butterworth) la respuesta es maximamente plana. Para Q > 0.707 aparece un pico de resonancia cerca de fc. Usa la sonda para encontrar empíricamente el punto −3 dB.
